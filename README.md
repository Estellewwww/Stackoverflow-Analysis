# Stack Overflow Platform Analysis

**PySpark · SQL · Python · Large-scale data analysis**

A collaborative final project for **IS843: Big Data Analytics for Business**, analyzing activity on Stack Overflow through three complementary views.

## Analysis areas

| Area | Focus |
| --- | --- |
| Users | User-level activity and participation |
| Content | Questions, answers, and platform content |
| Badges | Badge-related patterns and recognition |

## Explore

[Open the analysis notebook](notebooks_jupyter_IS3-Stack-Overflow-Platform-Analysis.ipynb) to review the workflow and stored outputs.

The project uses Python, PySpark, and SQL. Running the notebook requires a compatible Spark setup and the source data referenced in its cells; the original environment and all input data are not packaged as a standalone application.
